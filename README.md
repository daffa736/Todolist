Todo List App

Apk todo list berbasis web ini merupkan project dengan mengikuti materi dan kursus pengembangan web,apk ini untuk membantu kita agar lebih mudah mencatat,mengelola dan mengatur
daftar tugas atau kegiatan sehari hari,dan membantu pengguna menyimpan tugas secara ter organisir.

Fitur 
-Halaman Utama
-Menambah tugas
-Menghapus daftar tugas 
-Menandai tugas yang sudah selesai
-Menyimpan daftar tugas di local storage


 Teknologi 
 -HTML
 -CSS
 -JavaScript
 -Local Storage
